# OpenVINO GPU ScatterUpdate Bug with Remote Tensors

## Background

Running `llama-simple` with Phi-3-mini-4k-instruct (Q4_0) on the OpenVINO GPU backend produces incorrect output (e.g. "John Do Do Do Do" instead of coherent text). The root cause is that `ov::op::v3::ScatterUpdate` produces wrong results on GPU when a remote tensor is used as both input and output (in-place KV cache update).

The bug occurs on the **first infer call** — not just on repeated inferences. CPU produces correct results with the same in-place pattern.

## Observed behavior

- CPU row 5: `-0.2510 0.5933 0.9014 -0.6333 0.4639 ...`
- GPU row 5: `0.0000 0.0000 -0.1133 0.0202 -0.0550 ...`
- `max_diff = 3.5389` (entire tensor is corrupted, not just the scatter target row)

## Standalone Reproduce (scatter_reproducer)

### Prerequisites

- OpenVINO (tested with 2025.x)
- Intel GPU
- A KV cache tensor dump file (f16, shape [1,1,256,3072])

To generate the dump file, set `GGML_OPENVINO_DUMP_REPRODUCER=1` and run `llama-simple` with Phi-3 on GPU. This produces `reproducer_input_*_cache_k_l0.bin`.

### Build

```bash
cd tmp/reproducer
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release \
  -DOpenVINO_DIR=<path_to_openvino>/runtime/cmake
make
```

### Run

```bash
./scatter_reproducer <path_to_cache_k_l0.bin>
```

Expected output:
```
=== CPU: single infer ===
  After infer: row 5 (first 10 elements): -0.2510 0.5933 0.9014 ...

=== GPU (remote tensor in-place): single infer ===
  After infer: row 5 (first 10 elements): 0.0000 0.0000 -0.1133 ...

  CPU vs GPU max_diff = 3.5389
  BUG: GPU result differs from CPU!
```

## Key details

- Model: single `ScatterUpdate(data, indices=5, updates, axis=2)` node
- The remote tensor is created via `remote_context.create_tensor()` and set as both `input_tensor(0)` and `output_tensor(0)`
- Same bug reproduces with USM device tensors (`create_usm_device_tensor`)
- All 32 layers and both K/V caches are affected in the full model

## Full model reproducer

`reproducer.cpp` loads the full OpenVINO IR (72 inputs, 65 outputs) and compares CPU vs GPU. Requires the model IR and all input tensor dumps (generated by `GGML_OPENVINO_DUMP_REPRODUCER=1`).

```bash
./reproducer <model.xml> <input_dir>
```
